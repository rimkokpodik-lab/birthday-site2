# 📥 Сайт приёма дат рождения (.txt по HTTP)

Сайт принимает **txt-файлы** от студентов по адресу `POST /api/upload` и складывает их во «Входящие».
Студенты отправляют файл своим `.bat`-скриптом (или из кода), преподаватель скачивает всё из кабинета.

```
студент → bat → txt-файл → POST /api/upload → папка data/inbox → кабинет /admin → скачивание
```

Работает на чистом Node.js — **никаких зависимостей и базы данных** ставить не нужно.

---

## 🌍 Важно: сайт должен быть в интернете

`localhost` в bat-файле означает «этот самый компьютер». Если студент запустит такой bat
у себя, он постучится на **свой** ноутбук, где сайта нет — отсюда ошибка
`Unable to connect to the remote server`.

Чтобы файлы приходили от студентов, сайт должен быть доступен по **публичному адресу**
(`https://ваш-сайт.ru` или `http://192.168.1.50:3000` внутри одной сети).

**Порядок действий:**

| Ситуация | Что делать |
|---|---|
| Студенты в одном кабинете / одной Wi-Fi сети | Запустите сайт у себя, узнайте IP (`ipconfig`), подставьте `http://192.168.x.x:3000` в кабинете → «Настройки и .bat» → скачайте bat |
| Нужна ссылка из интернета | Задеплойте проект: **[deploy/README-хостинг.md](deploy/README-хостинг.md)** — пошагово, 5–10 минут, есть `Dockerfile` и `render.yaml` |

> Предпросмотр внутри Arena для студентов **не подойдёт**: он закрыт платформенным токеном
> и работает только пока открыта эта сессия.

## 🚀 Запуск

**Windows:** двойной щелчок по `start.bat` (нужен Node.js с [nodejs.org](https://nodejs.org)).
**Mac / Linux:** `./start.sh` или `node server.js`.

- Страница студентов: `http://localhost:3000`
- Кабинет преподавателя: `http://localhost:3000/admin`
- Пароль по умолчанию: **`urok2026`** (меняется в `config.json` или в кабинете)

## 🔁 Как это работает

### 1. В bat-файле указан адрес сайта

> **Тексты внутри bat-файла** (заголовки, вопросы, сообщения) меняются в кабинете:
> вкладка **«Настройки и .bat» → блок «Тексты внутри bat-файла»** → правите поля →
> «💾 Сохранить тексты» → скачиваете bat заново. Правки сразу попадают в готовый файл.
> Если правите bat вручную, помните: файл должен остаться в кодировке **CP866**
> (или UTF-8 вместе с `chcp 65001`) и с переводами строк **CRLF** — иначе русский текст
> в консоли превратится в «кракозябры». Проще скачать файл из кабинета.
Внутри `bat/otpravka-dnya-rozhdeniya.bat` есть строка:

```bat
set "URL=https://ваш-сайт.ru/api/upload"
```

Именно туда уходит txt-файл. Адрес можно вписать руками прямо в bat,
либо скачать готовый файл из кабинета (вкладка **«Настройки и .bat»**) — адрес подставится автоматически.

### 2. Студент запускает bat
Скрипт спрашивает ФИО, группу и дату рождения, собирает `birthday.txt`, проверяет дату
и отправляет файл на сайт через PowerShell (с поддержкой HTTPS/TLS 1.2). Если PowerShell
заблокирован — автоматически пробует резервный способ через `curl` (есть в Windows 10/11).

Дополнительно bat:
- «прогревает» сайт запросом `/healthz` — если хостинг засыпал, он успеет проснуться;
- делает **3 попытки** отправки с паузой 5 секунд;
- при ошибке объясняет по-русски, что проверить, и **открывает txt-файл** с данными,
  чтобы студент мог переслать его вручную.

Содержимое отправляемого файла:

```
ФИО: Иванов Иван
Группа: ИС-21
Дата рождения: 12.05.2005

Отправлено: 28.10.2026 15:00
Компьютер: LAB-01
Пользователь: student
```

### 3. Файл появляется на сайте
Он сохраняется в `data/inbox/` и попадает в список «Входящие файлы» вместе с расшифрованными
ФИО, группой и датой рождения. Кодировка определяется автоматически: UTF-8, UTF-16, CP1251, CP866.

### 4. Вы скачиваете файлы
- **⬇** — скачать исходный txt-файл студента;
- **👁 Показать** — текст файла в браузере (работает всегда, даже если скачивание блокируется);
- **⬇ Скачать все (.zip)** — архив всех файлов с понятными именами `001_Иванов Иван.txt`;
- **⬇ Все в один .txt** — один общий файл со всеми данными.

Дополнительно есть вкладка **«Список дней рождения»**: сводная таблица с возрастом,
ближайшим ДР и выгрузкой в TXT/CSV, а также ручным добавлением учеников.

## 🔌 API приёма файлов

**Адрес:** `POST /api/upload` — публичный, пароль не нужен (так задумано: файл должен прийти от студента).

| Что | Значение |
|---|---|
| Метод | `POST` |
| Тело запроса | содержимое txt-файла (текст в UTF-8) |
| Необязательные заголовки | `X-Filename: birthday.txt` — под каким именем сохранить |
| Ответ | `?text=1` или `Accept: text/plain` → строка `OK: файл принят…`, иначе JSON |

Псевдонимы адреса: `/api/send`, `/api/birthday`. CORS открыт (`Access-Control-Allow-Origin: *`).

**curl**
```bash
curl -X POST -H "Content-Type: text/plain; charset=utf-8" \
     --data-binary @birthday.txt "http://localhost:3000/api/upload?text=1"
```

**PowerShell**
```powershell
$body = [IO.File]::ReadAllBytes("birthday.txt")
$wc = New-Object Net.WebClient
$wc.Headers.Add("X-Filename", "birthday.txt")
$wc.UploadData("http://localhost:3000/api/upload?text=1", "POST", $body)
```

**Python**
```python
import urllib.request

data = open("birthday.txt", "rb").read()
req = urllib.request.Request(
    "http://localhost:3000/api/upload?text=1",
    data=data,
    headers={"Content-Type": "text/plain; charset=utf-8",
             "X-Filename": "birthday.txt"},
)
print(urllib.request.urlopen(req).read().decode("utf-8"))
```

Сайт понимает и «сырой» формат без подписей: если в файле есть только строка с датой
и ФИО, преподаватель всё равно увидит данные, а файл сохранится как есть.

## 🌐 Доступ для студентов

**В одной сети (кабинет/класс):**
1. Запустите сайт на своём компьютере.
2. Узнайте IP: `ipconfig` → `IPv4-адрес`, например `192.168.1.50`.
3. Адрес для bat: `http://192.168.1.50:3000/api/upload`.
4. Разрешите Node.js в брандмауэре Windows.

**Постоянная ссылка в интернете:**
- **Render / Railway / Fly.io** — запуск `node server.js`, переменные `PORT` и `ADMIN_PASSWORD`,
  постоянный диск, чтобы файлы не пропадали.
- **VPS (Timeweb, Beget, REG.RU…)** — `pm2 start server.js --name birthdays` + nginx как reverse proxy для домена и HTTPS.

После публикации впишите адрес в кабинете: **«Настройки и .bat» → Публичный адрес сайта** →
скачайте bat — он будет отправлять файлы уже на новый адрес.

> ⚠️ Публичный адрес должен быть доступен студентам по HTTPS/HTTP без авторизации —
> иначе bat не сможет отправить файл.

## ⚙️ Настройки (`config.json`)

```json
{
  "schoolName": "Школа №5, г. Мыски",
  "adminPassword": "urok2026",
  "publicUrl": "",
  "groupLabel": "Группа",
  "batTexts": {
    "window": "Отправка даты рождения",
    "header": "ОТПРАВКА ДАТЫ РОЖДЕНИЯ ПРЕПОДАВАТЕЛЮ",
    "namePrompt": "Фамилия и имя",
    "groupPrompt": "Группа (можно пропустить)",
    "datePrompt": "Дата рождения (ДД.ММ.ГГГГ)",
    "sending": "Отправляю файл на сайт...",
    "success": "Готово! Ваши данные получены преподавателем.",
    "fail": "Не удалось отправить файл автоматически."
  }
}
```

Поле `batTexts` — это и есть все надписи, которые видит студент в чёрном окне.
Менять их удобнее в кабинете, но можно и здесь — тогда перезапустите сайт.

Всё то же самое можно менять прямо в кабинете на вкладке «Настройки и .bat».

На хостинге эти значения удобнее задавать переменными окружения:

| Переменная | Зачем |
|---|---|
| `PORT` | порт (обычно задаёт сам хостинг) |
| `ADMIN_PASSWORD` | пароль кабинета |
| `SCHOOL_NAME` | название на страницах |
| `PUBLIC_URL` | публичный адрес — автоматически попадает в bat |
| `DATA_DIR` | куда складывать файлы (постоянный диск), например `/var/data` |

```
birthday-site/
├── server.js                        сервер: приём файлов, кабинет, экспорт, ZIP
├── config.json                      название, пароль, публичный адрес
├── start.bat / start.sh             запуск в один клик

├── render.yaml                      конфиг деплоя на Render (с постоянным диском)

│   └── otpravka-dnya-rozhdeniya-utf8.bat тот же bat в UTF-8 (если включён 65001)
├── data/
│   ├── inbox/                       полученные txt-файлы
│   ├── inbox.json                   их описание (дата, IP, распознанные поля)

    ├── index.html                   страница студента (+ примеры для программистов)

    └── style.css                    оформление
```

**Резервная копия** — просто скопируйте папку `data/`.
